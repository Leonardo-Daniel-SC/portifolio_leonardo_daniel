# 👨‍💻  Sobre o projeto

Este portfólio foi desenvolvido para apresentar minha trajetória na tecnologia, meus conhecimentos, projetos e formas de contato. A interface conta com um design moderno, animações, navegação por seções e layout responsivo.

### ✨ Funcionalidades

- Apresentação pessoal e trajetória profissional.
- Seção de projetos com links para os repositórios e aplicações.
- Exibição das principais tecnologias estudadas.
- Navegação entre seções e menu adaptado para dispositivos móveis.
- Animações e efeitos visuais para melhorar a experiência de navegação.
- Download do currículo em PDF.
- Links para contato e redes profissionais.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estruturação do conteúdo |
| CSS3 | Estilização, responsividade e animações |
| JavaScript | Interatividade e manipulação de elementos da página |
| SVG | Ícones vetoriais |
| Google Fonts | Tipografia com Inter e Poppins |

## 📂 Projetos em destaque

### 📦 Controle de Estoque
Sistema desenvolvido em Python com banco de dados SQLite para gerenciamento de estoque.

**Tecnologias:** Python, SQLite.

[🔗 Acessar repositório](https://github.com/Leonardo-Daniel-SC/controle-estoque-python)

### 🚀 AstroLab em Arduino
Sistema embarcado desenvolvido para simular o monitoramento de um ambiente em missões espaciais.

**Tecnologias:** Arduino, C++, Wokwi.

[🔗 Acessar repositório](https://github.com/Leonardo-Daniel-SC/AstroLab)

### 💡 Smart Lamp
Projeto de IoT para controle e monitoramento de uma lâmpada inteligente, integrando hardware, comunicação MQTT e serviços em nuvem.

**Tecnologias:** ESP32, MQTT, FIWARE, React e AWS.

[🔗 Acessar repositório](https://github.com/Leonardo-Daniel-SC/controle_lampada)

### ✅ Gerenciador de Tarefas
Aplicação web desenvolvida para criar, organizar e gerenciar tarefas, utilizando armazenamento local no navegador.

**Tecnologias:** React, Vite e LocalStorage.

[🔗 Acessar repositório](https://github.com/Leonardo-Daniel-SC/Gerenciador-de-Tarefas)

### 🎮 Jogo do Número Secreto
Jogo interativo em que o usuário precisa descobrir um número gerado aleatoriamente pelo sistema.

**Tecnologias:** HTML5, CSS3 e JavaScript.

[🔗 Acessar repositório](https://github.com/Leonardo-Daniel-SC/Jogo-numero-secreto)
